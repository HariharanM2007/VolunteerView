Project Overview
The system orchestrates a non-profit volunteer engagement and management platform, natively facilitating administrator-managed user approval and organization oversight with transactional status lifecycle enforcement, coordinator-driven opportunity creation and enrollment management with capacity validation, volunteer-led enrollment with automated status progression, and platform-wide impact analytics. It provides structural entry points for registering non-profit organizations with PENDING APPROVED status gating, creating volunteer opportunities with DRAFT - OPEN CLOSED COMPLETED lifecycle enforcement, enrolling volunteers with capacity-check and duplicate-prevention guards, progressing enrollments through PENDING - APPROVED states, and submitting impact reports tied to COMPLETED enrollments with hours-contribution validation. -STARTED COMPLETED
The system enforces role-based access control dynamically allocating distinct application privileges for PLATFORM_ADMIN, ORGANIZATION_COORDINATOR, and VOLUNTEER roles inherently. All interactions strictly utilize a stateless filter topology that executes the standard HS256 JWT algorithm implicitly signing JSON Web Tokens with dual-token (access + refresh) pair issuance to prevent unauthorized session modifications and natively restricting data access by role and organizational affiliation internally safely.

Security Implementation
JWT signing algorithm: HS256
JwtService class location: com.example.demo.security.JwtService (annotated @Service). This is the class used by JwtAuthenticationFilter.
JwtService field: secretKey - private String, injected via @Value("${jwt.secret)"). Decoded via Base64.getDecoder().decode(secretKey).
JwtService field: accessTokenExpiration - private long, injected via @Value("${jwt.access-token-expiration)").
JwtService field: refresh TokenExpiration private long, injected via @Value("${jwt.refresh-token-expiration)").
JwtService method: generateAccess Token (SystemUser user) - adds extra claims. role=user.getRole().name(), userid=user.getId(), fullName=user.getFullName(). Calls build Token with access TokenExpiration.
JwtService method: generate Refresh Token (SystemUser user) - adds extra claims role=user.getRole() name(), token Type="REFRESH". Calls buildToken with refresh TokenExpiration.
JwtService private build Token(Map<String, Object> extraClaims, String subject, long expiration) builds JWT via Jwts builder(), sets claims, subject, issuedAt, expiration signs with Jwts SIG HS256 and getSigningKey()
JwtService method is TokenValid(String token, String username) - returns (extractUsername(token) equals(username)) && lis TokenExpired(token).
JwtService method: extractUsername(String token) extracts Claims getSubject
JwtService method: extractRole(String token) extracts claims get("role", String class)
JwtService method is TokenExpired(String token) - returns extractExpiration(token) before(new Date())
JwtService private getSigningKey()-returns Keys hmacShakeyFor (Base64 getDecoder() decode(secretKey))
